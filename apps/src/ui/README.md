# 🎨 Meta Astryx UI System (`@forge/ui`)

Meta Astryx Design System v2.0.0 LTS tokens, CSS variables (`--forge-*`), dual-palette theme engine, and animated Sun/Moon header components.

---

## 🛠️ Exports
* `themeTokens`: Dual palette tokens for `dark` and `light` themes.
* `getAstryxStyles()`: High-contrast, responsive CSS string with glassmorphism variables.
* `getAstryxHeaderHtml()`: Standard navigation header with interactive animated Sun/Moon theme toggler and cross-tab `localStorage` persistence.
