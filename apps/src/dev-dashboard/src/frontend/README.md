# 🎨 Dev Dashboard Frontend Engine (`src/frontend/`)

Meta Astryx single-page application (SPA) developer interface for `@forge/dev-dashboard`.

---

## 📂 Modules
- **`ui-styles.ts`**: Full-width top header, below-header sidebar layout, and 80% compact Meta Astryx CSS variables.
- **`ui-scripts.ts`**: Interactive SPA tabs, SSE realtime stream subscribers, theme toggle synchronization, and SQL runner.
- **`ui-renderer.ts`**: High-density HTML document compiler.
