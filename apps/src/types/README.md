# 📐 Forge Domain Types (`@forge/types`)

Shared TypeScript interfaces, RBAC models, organizational canvas entities, and postMessage payload contracts.

---

## 🛠️ Key Interfaces
* `UserContext`: Authenticated user identity and permission scopes.
* `CanvasNode` & `CanvasEdge`: Visual 2D organizational canvas structures.
* `PostMessageEvent`: Bidirectional iframe communication contract.
