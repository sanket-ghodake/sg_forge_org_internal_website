# 🛠️ Developer Hub & SDK Playground (`@forge/dev-hub`)

Developer onboarding, SDK documentation, token inspection, and micro-app scaffolding interface serving on Port `:3003` (proxied at `/gateway`).

---

## 🚀 Features
* **Forge SDK Specs**: Interactive postMessage handshake explorer.
* **Scaffolding Guide**: 1-command micro-app creation workflows (`./run.sh create-app <name>`).
* **Meta Astryx UI**: Clean dark/light theme integration via `@forge/ui`.

---

## 🏃 Local Execution
```bash
bun apps/src/dev-hub/src/server.ts
```
